# ActividadDesarrolloWeb

Práctica: Mi primer repo colaborativo en GitHub

Objetivo:
Aprender a colaborar con tu equipo usando Git y GitHub de forma sencilla y real.

¿Qué vamos a hacer?
Cada quien clonará un repositorio compartido, agregará su nombre a un archivo y subirá el cambio. Así todos dejan su huella en el proyecto.

Al final:
Tendremos un solo archivo (participantes.md) con todos los nombres del equipo, demostrando que ya le sabes al trabajo en equipo con control de versiones.
